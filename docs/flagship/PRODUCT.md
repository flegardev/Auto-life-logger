# Auto Life Logger — flagship redesign

Understand your browsing. Keep your history private.

## Delivered

Calm light dashboard and popup; seven-day review; transparent productive-time goal; category explanation; quiet onboarding; improved chart contrast; overlapping category flags no longer double-count in overview.

## Compatibility

Existing identity, permissions and legacy storage keys are preserved. New preferences use separate keys or additive vehicle fields. No tracking backend or telemetry was added.

## Candidate

Version 2.3.0. Rebuild with `npm ci` and `npm run package` in `.`. Run `npm run test:extension` for legacy and new browser journeys. Fixtures use disposable Chromium profiles. They do not represent real participant research.

## Limits

Browser activity is not whole-device activity or work quality. Legacy category flags reflect capture-time rules. The published Store ID and package still need independent confirmation.
